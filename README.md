# 今日加餸 · Dace Meets Greens

Interactive food website: scroll-driven canned-dace video, unfolding recipe brochure, and an interactive dining table.

## Local preview
Serve `dist/` with a static HTTP server supporting byte-range requests for video seeking. No build step is needed.

## Contents
The dist directory contains only the website runtime and its media. The repository is private; the deployed review website is shareable. Original artwork, media and custom handwriting belong to their respective owners. WenKai font license is included in dist/assets/wenkai-OFL.txt.
